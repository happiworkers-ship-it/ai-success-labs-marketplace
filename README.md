# AI Success Labs Marketplace

The official Claude Code plugin marketplace for students of the **Brand Magnetism Accelerator** by Ngozi Cadmus — AI Success Labs.

> Build a magnetic LinkedIn brand with AI. Turn your expertise into income, authority, and influence — without hustle culture.

## Install in 30 seconds

In any Claude Code session:

```
/plugin marketplace add happiworkers-ship-it/ai-success-labs-marketplace
/plugin install brand-magnetism-starter@ai-success-labs-marketplace
```

That's it. You now have the full Brand Magnetism Accelerator student toolkit.

## What's inside

The `brand-magnetism-starter` plugin gives you 6 skills working together as one system:

| Skill | What it does |
|-------|--------------|
| **5-day-brand-engine** | The Monday–Friday LinkedIn content strategy. Tells you what to post each day (TOFU / MOFU / BOFU). |
| **post-architecture** | The Hook → Develop → Deliver → Close framework for every post you write. |
| **my-linkedin-voice** | A template you fill in with YOUR voice, audience, offers, and credentials. Used by the engine to make every post sound like you. |
| **linkedin-content-engine** | The all-in-one pipeline. Say "what should I post today?" — it picks the funnel stage, drafts the post in your voice, and gives you the matching visual prompt. |
| **linkedin-image-prompt** | Turns any post into 3 editorial image prompts ready to paste into your image generator (Gamma, Midjourney, ChatGPT, etc). |
| **infographic-prompt** | Turns raw content into ready-to-paste infographic prompts for Canva, Napkin AI, Gamma, Piktochart, Visme, and more. |

## First step after installing — fill in your voice

The engine needs YOUR voice to write posts that sound like YOU.

1. Open the file: `my-linkedin-voice/SKILL.md` inside the plugin
2. Replace every `[Your Name]`, `[your role/title]`, `[your audience]` placeholder with your real details
3. Save

Then say to Claude: *"What should I post on LinkedIn today?"* — and the engine takes it from there.
